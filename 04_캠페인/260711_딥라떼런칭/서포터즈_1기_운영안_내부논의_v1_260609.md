## 0. 한 줄 정리

> **6월 1기 = "구조를 검증하는 실험"(인원 미정 · 내부 공지 모집). 허들은 낮게, 동력은 월 10만원 + 활동 증명서로. 가이드는 딥라떼 인플루언서 가이드에서 축약. 7월 폼 출시(솔티드·너티·말차) 때 본가동할 라인을 6월에 미리 깐다.**

## 1. 왜 서포터즈인가 — 딥라떼 인플루언서와 역할 분리

두 라인을 **섞지 않는다.** 비용·운영·콘텐츠 성격이 다르다.

| 구분 | 딥라떼 인플루언서 (Part 2) | 서포터즈 (Part 3 설계 → 별도 활동비) |
|---|---|---|
| 누구 | 외부 맛집·라떼·경남 일상 **마이크로 계정** | **매장 알바생** (내부) |
| 관계 | 섭외·브리프·유료 1회성 | 모집·온보딩·지속 활동 |
| 콘텐츠 | "발견형" — 소비자가 우연히 본 듯 | "자생형" — 매장 사람의 일상 |
| 통제 | 브리프 가이드 | 최소 가이드 + 자율 |
| 회수 | 협업물 그대로 | 우수분 **공식 리포스트로 흡수** |
| 비용 | 시딩비(섭외 단가) | 활동비·인센티브(별도 결정 필요) |

> 메가커피 사례: 알바 자생 콘텐츠가 이미 많지만 브랜드가 흡수 안 해 자산화 실패. 댄싱컵은 **자생 + 흡수** 구조로 차별. (출처: `05_앰버서더.md` §1-4)

## 2. 1기의 성격 — 6월은 "실험", 7월부터 "본가동"

- **6월:** 출시 전 인지도 빌드업 기간. 서포터즈는 **소규모로 구조만 검증** — 모집 흐름·온보딩·검수·정산이 굴러가는지 확인.
- **7월:** 폼 3종 출시 D-Day에 맞춰 **일제 콘텐츠 가동**. 1기에서 검증된 구조를 그대로 확장.
- 1기 = 완성형이 아니라 **다음 기수 설계를 위한 파일럿**. 그래서 인원·기간·금액을 크게 잡지 않는다.

## 3. 모집 (Recruit)

### 3-1. 대상·자격
- **대상:** 댄싱컵 매장 알바생 (점주 동의 전제)
- **지역:** **부산권 우선** (1기는 거점 집중 → 관리·촬영 협조 용이)
- **자격:** 인스타 / X / 틱톡 **중 1개 이상 활성 계정** 보유
- **불요:** 팔로워 수·제작 경력·포트폴리오 (허들 ↓ — 4/29 미팅 절충 기조 유지)

### 3-2. 규모 — 미정으로 진행 (확정)
- **인원은 정하지 않고 진행.** 1기는 실험이므로 목표 인원을 못 박지 않고, **내부 공지에 응답하고 자격을 충족한 알바생을 받는 만큼** 가동.
- 모이는 규모에 따라 7월 본가동 시 정원·기수 설계를 역산.
- 외부 문서엔 인원 자체를 표기하지 않음(기존 원칙 유지).

### 3-3. 모집 방식 — 내부 공지 (확정 · 세부는 내부 확인)
- **방식 = 매장 내부 공지** (점주 통해 알바생에게). 공식 SNS 공개 모집 아님.
- 공개 모집 폼은 만들지 않고 **내부 안내문 + 간이 신청서**로 처리.
- 🔸 **내부 확인 필요:** 공지 채널(본사 단톡 / 매장 공지문 등)·점주 전달 방식 등 운영 디테일은 내부에서 확정.

### 3-4. 간이 신청서 (내부 · 허들 ≤ 5분)
| 필드 | 형식 |
|---|---|
| 이름·연락처 | 텍스트 |
| 근무 매장 | 드롭다운(매장 리스트) |
| 활성 SNS 핸들 | 텍스트 (인스타/X/틱톡 중) |
| 한 줄 ("내가 일하는 매장은 우리 동네에서 ___") | 50자 |
| 자유 콘텐츠 1개 | 기존 게시물 링크 OR 휴대폰 30초 영상 |
| 활동 의향 | 체크박스 |

## 4. 활동 구조 (What they do)

### 4-1. 콘텐츠 종류 — 2갈래
| 갈래 | 성격 | 가이드 강도 |
|---|---|---|
| **① 정규(통일)** | 신메뉴·시즈널 시 매장 시연 | 본사 컷가이드 + 본인 변주 |
| **② 자유(자생)** | 매장·딥라떼 일상, 썰, 조합 | 금지어만 / 톤·소재 자율 |

> 시리즈 아이디어(과거 리서치 차용, 강제 아님): "점주의 꿀조합" · "신메뉴 리뷰" · "카페 썰툰". 1기엔 **②자유 위주로 가볍게**, 7월부터 ①정규 비중↑.

### 4-2. 빈도 — 월 2~3개 (확정)
- **월 2~3개 / 자유 콘텐츠 위주.** 실험 단계라 부담을 낮춘다.
- 7월 폼 본가동 시 정규 콘텐츠 비중을 올리며 빈도 재조정.
- 외부 문서엔 "월 N개" 미기입(기존 원칙 유지).

### 4-3. 채널
- 본인 활성 계정 1개에 업로드 → 공식 해시태그 의무: **#댄싱컵딥라떼** (+지역 태그 옵션)
- 우수분은 공식 인스타·X가 **리포스트로 회수**.

## 5. 운영 가이드 (입문 OT에서 전달)

> **가이드 베이스 = 딥라떼 인플루언서 가이드.** 인플루언서용으로 만든 콘텐츠 가이드(딥라떼 정의·금지어·표기·"폼은 7월")를 **그대로 축약**해 서포터즈용 최소 가이드로 전환 — 별도 신규 가이드를 새로 쓰지 않고 한 뿌리에서 파생. *(축약본은 별도 작성 예정 — §9 체크리스트)*
> **참고 레퍼런스(알바생 활용 타브랜드):** GS25 25매거진 · 올리브영 "올리브영다움" · 메가커피 알바 자생 콘텐츠 등 — OT 자료에 사례로 첨부 (출처: `05_앰버서더.md` §1).

**고정(반드시 지킴):**
- 딥라떼 정의 한 줄 (무엇을 딥라떼라 부르는지)
- 금지 어휘: 기업 어투 / 경쟁사 직접 디스 / 성과·가성비 자랑 / 정치·종교
- 표기: 협찬·활동 표기(필요 시), 공식 해시태그
- 7월 전까지 **폼(맛) 언급 자제** — 6월은 딥라떼 맛 인지에 집중

**자율(건드리지 않음):**
- 톤·말투·편집·소재·업로드 시간 — 매장마다 결이 다른 게 핵심 가치

**검수 흐름:**
- 정규 콘텐츠 = **사전 가벼운 확인**(가이드 컷 포함 여부)
- 자유 콘텐츠 = **사후 모니터링**(24시간 내) — 동력 위해 빠른 피드백

## 6. 인센티브·정산 (방향 확정)

- **활동비 = 월 10만원 / 인.** 1기 실험 규모에 맞춘 소액 정액 (콘텐츠 의무 충족 시 지급).
- **활동 증명서 = 기수 종료 시 일괄 발급.** 1기 활동 완료자에게 "댄싱컵 서포터즈 1기 활동 증명서"를 **기수 종료 시점에 발급** — 알바생에게 **이력·경험 자산**이 되는 비현금 동력(현금 외 유인).
- (옵션, 추후) 조회수 보너스·분기 베스트 매장 시상 = 7월 본가동 때 검토.

> ⚠️ **예산 출처 확인 필요:** 활동비(월 10만 × 인원)는 현재 견적에 라인이 없음. Part 3 "서포터즈 모집·운영안(50만)"은 설계·매니징비. → **별도 예산 또는 리테이너 내 재배분**을 내부 정리. 인원 미정이므로 월 총액은 응답 규모에 연동(예: N명 → 월 10만×N).
