## 1. 흑임자 — 브랜드가 한 일

### 1-1. 공차 흑백밀크티 (2026-01) — **대결 포맷의 직접 선례**

댄싱컵 9월 기획과 구조가 거의 같다. 흑임자를 대결의 한 편으로 세웠다.

| 순서 | 실행 |
|---|---|
| 사전 | 인스타로 협업 예고 → **6일간 '흑 VS 백 댓글 투표'** |
| 출시일 | 메인 영상 '돌아버린 흑백 티 마스터' — 윤남노 셰프가 흑·백 **두 캐릭터로 1인 2역** |
| 출시 후 | **흑백 스크래치 쿠폰** — 음료 구매 시 난수 번호 제공 → 앱 등록 → 즉시 당첨 확인 |
| 확산 | 구매 인증샷 이벤트 순차 전개 |

라인업 4종 = 黑흑임자 밀크티+펄 · 흑임자 크림 커피 / 白소금 밀크티+미니펄 · 소금 얼그레이 크림 커피
**대결 축 = 흑임자 vs 소금** (고소함 vs 단짠)

> 판독: 대결 포맷 자체는 이미 쓰였다. 댄싱컵이 "대결"만으로는 새롭지 않다. 차이를 어디서 낼지가 관건.

### 1-2. 이디야 흑임자크림 라떼 (2022-10-25) — 음료 + 푸드 동시 출시

- 음료 2종(흑임자크림 라떼 · 흑임자크림 카페라떼) + **흑임자 붕어빵 2종을 같은 날 출시**
- 3주 20만 잔 · 일 평균 1만 개 · 전체 밀크베버리지 판매 **3위**(토피넛라떼·초콜릿 다음)
- 붕어빵도 3주 13만 개
- 시즌 한정 4개월(10/25~2/27) — **가을 시작에 내서 겨울을 관통**

> 판독: 흑임자는 음료 단독보다 **씹는 것과 붙었을 때** 숫자가 커졌다.

### 1-3. 이디야 국중박 시그니처 라떼 (2026) — 장소 특화

- 국립중앙박물관 내 5개 매장 전용 검은깨 라떼
- 결제 데이터 분석 결과 **외국인 주문 1위** · 흑임자 증편은 전체 7위
- 같은 라인에 김부각 밀크쉐이크·배모과 에이드·팥 모나카

### 1-4. 달콤커피 흑임자 라떼 3종 (2019-11) — 지역 유행의 이식 + 굿즈

- **"강릉에서 인기인 트렌디한 메뉴"라고 명시하고 프랜차이즈로 가져옴**
- 3종 = 흑임자 라떼 / 흑임자 초코 라떼(입문용) / 흑임자 카페 라떼
- 폰 스트랩 **3만 개 한정** — 1만 원 이상 구매 시 무료, 신메뉴 1잔 구매 시 1,900원

### 1-5. 롯데칠성 칸타타 흑임자카페라떼 (2023-05) — 발굴 프로젝트

'모두의 시그니처' = 전국 소상공인 카페의 시그니처 메뉴를 찾는 프로젝트

1. 사전 심사로 전국 카페 6곳 선정

3. 최우수작(천안 '인사이트 커피' 흑임자카페라떼)을 RTD로 출시
4. 패키지에 원조 카페의 파란 대문(사진 맛집) 삽입 · **QR로 탄생 스토리 영상**

### 1-6. 이디야 × 우유자조금 '라떼대회' (2020-11) — 레시피 공모

- 비대면 온라인 대회 · 168개 출품 → 59개 선정
- **최우수상 = 흑임자 라떼**

### 1-7. 공차 흑임자 밀크티 + 펄

흑임자 베이스 + 타피오카 펄 + **흑임자 폼** — 출시 즉시 인기

### 1-8. 투썸 흑임자 팥 빙수 (2026)

빙수 신제품 주재료로 흑임자 채택. 근거를 **K-푸드 글로벌 관심**으로 잡음

### 1-9. 더벤티 흑임자폼라떼 (2025-09) — 저가권 유일 선례

## 2. 쑥 — 브랜드가 한 일

### 2-1. 빽다방 쑥쑥라떼 · 쑥쑥빽스치노 (2021-12) — **저가권 선례, 그리고 겨울 출시**

- 겨울 시즌 메뉴로 출시. **봄이 아니다**
- 소구 각도 = "건강한 식재료" · 쌉싸름한 풍미를 은은하게 = **호불호 없이**
- 빽스치노는 소프트아이스크림 토핑 선택 가능
- **우유 → 두유 변경 +500원 옵션** 제공

> 판독 2건. ① 저가권에서 쑥을 겨울에 낸 전례가 있다 — "가을 쑥"이 이상하지 않다. ② 밀크 베이스 변경을 **유료 옵션**으로 판 선례가 있다.

### 2-2. 스타벅스 부드러운 쑥 팥 생크림롤 — 1개 지점 → 전국

꿀인삼설빙 / **쑥찰떡설빙 / 흑임자찰떡설빙** — 둘을 갈라 세우지 않고 묶어서 냈다

## 4. 2026 저가권 액션 문법

원재료와 무관하게, 지금 저가 커피에서 실제로 작동한 방식.

### 4-1. 접점의 8할이 키오스크다

한국소비자원 저가커피 4사 조사 — **주문 10건 중 8건이 키오스크**. 종합 만족도는 컴포즈 3.97 > 메가 3.93 > 더벤티 3.86 > 빽다방 3.73. 불만 1위는 커피 맛(41.4%).

### 4-2. 메가 '나폴리탄 괴담 영수증' (2026-07-09) — 영수증이 미디어

- 여름 신메뉴 6종 콘셉트 = '오싹오싹 엠지씨네 여름밤'
- **키오스크 영수증에 괴담 문구 인쇄** — "붉은 스무디의 흔적을 남기지 마십시오" / "치즈가 늘어날 때 뒤를 돌아보지 마십시오"
- 매장 DID(주문번호) 화면에도 콘셉트 영상 송출
- 결과: 자발적 인증샷 확산 · X 게시물 **리트윗 1.9만 · 490만 뷰** · 2주 누적 100만 개
- 디저트 '와앙 핫 치즈스틱' 치즈 늘어나는 리뷰 영상 190만 뷰

### 4-3. 컴포즈 '매샷추' (2026-03) — 알바생 릴스를 정식 메뉴로

- 알바생이 개인 SNS에 올린 매실차+에스프레소 릴스가 **70만 뷰**
- 본사가 레시피를 정식 메뉴로 채택 + 해당 알바생에게 **'SNS 홍보상' 시상**
- 별도 대규모 마케팅 없이 **2주 30만 잔**
- 업계 평가: 현장 아이디어 → SNS 검증 → 본사 상품화의 "사전 검증형 모델"

### 4-4. 메가 '여름휴가를 주문하세요' (2026-07) — 응모를 주문 행위로

앱에서 시즌 메뉴 + **'여름휴가' 항목을 함께 장바구니에 담아 주문**하면 자동 응모. 주문 횟수가 많을수록 당첨 확률 상승

### 4-5. 메가 슈퍼주니어 컵홀더 (2026-01) — 컵홀더가 굿즈

친필 사인 컵홀더를 매장 비치 → SNS 인증 이벤트. 매장별 조기 품절, "컵홀더 찾아 매장 순례" 반응

### 4-6. 메가 '멋쟁이 토마토 스무디' — 지자체 상생

춘천시 협업. 여름 신메뉴 6종 중 베스트셀러

### 4-7. 창억떡 호박인절미 (2026-03) — 유튜버 한 명이 만든 유행

- 구독자 77만 '하말넘많' 광주 브이로그에서 언급
- X 실시간 트렌드 진입 → '떡지순례' → 네이버 검색지수 20~50 → **100**
- 원래 유명했던 것이 **"현지에서 갓 만든 것"이라는 각도로 재점화**

### 4-8. 빽다방 가을 라인업 — 경쟁 참고

10월 출시 꿀밤·고구마 3종을 3년째 유지. 겨울 시즌 음료 평균 판매량 전년비 **+19%**, 꿀밤·고구마 3종은 **+22%**

| 셀럽 모델 | 메가 손흥민 · 컴포즈 뷔 · 더벤티 지드래곤 · 매머드 김우빈 — 예산 자릿수가 다름 |
| 푸드 동시 출시(붕어빵형) | 이디야 사례는 강력하나 **디저트 개발은 HIZ 영역 밖**. 관찰로만 전달 |
| 굿즈 제작(폰스트랩·컵홀더 디자인) | 물리 제작물 = HIZ 영역 밖. 기획 제안까지만 |
| 통신사·페이 제휴 | 백미당 사례. 본사 제휴 사안 |
| 팝업스토어 | 스타벅스 성수. 예산·권한 초과 |
| RTD 상품화 | 롯데칠성 칸타타. 제조 영역 |

### 확인 필요

- 댄싱컵 키오스크 영수증 문구를 본사에서 일괄 제어할 수 있는지 (영수증 액션의 전제)
- 지점 크루 대상 사내 공지·시상 경로가 있는지 (레시피 공모의 전제)
