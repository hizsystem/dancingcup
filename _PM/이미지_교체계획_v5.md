## 2. 조치 옵션 (❌ 항목)

벤치마크/사례 이미지는 셋 중 택일:

- **(A) 제거 + 텍스트화** _(권장·기본)_ — 사진 빼고 "브랜드명 + 무엇을 했나 + 결과 + 출처 링크"만 카드로. 저작권 0, 근거 유지. 시각 임팩트만 약간 손해.
- **(B) 자체 도식화** — 사례를 우리가 다이어그램/픽토그램으로 재해석(예: "꾸덕라떼 = 질감 키워드 선점" 도식). 저작권 0 + 시각 유지. 제작 공수 있음.
- **(C) 정식 인용 유지** — 썸네일 소형화 + `<span class="src">` 출처 명시. 공정이용 회색지대 — **정식 배포엔 비권장**, 내부/클라 1:1 한정.

> 9번 crew ref(이디야·달리는커피)는 (A) 텍스트 인용이 자연스럽다 — "타사도 알바생/서포터즈 콘텐츠로 운영" 한 줄이면 충분.
